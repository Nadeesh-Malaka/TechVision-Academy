# TechVision IT Academy Website

A modern multi-page website built using HTML and CSS for an IT education institute.

<img width="1291" height="599" alt="image" src="https://github.com/user-attachments/assets/94371eab-1068-457a-a480-acd179e585d7" />

## 🚀 Features

- Responsive design for desktop and mobile
- Clean and modern user interface
- Multi-page structure (Home, Courses, About, Contact)
- Course listing with card-based layout
- Video section for learning experience
- Testimonials and statistics sections
- Contact form layout
- Smooth scrolling and animations

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
